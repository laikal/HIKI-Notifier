# Source Notes

This directory contains the HIKI Notifier v1.11c C# source, project files, tests, and language files.

Visual assets, icons, character artwork, platform artwork, and the third-party audio asset used by the distributed application are not included in this public source directory. Resource references remain in the project and code; replacement assets are required to build the application exactly like the distributed binary.

User settings, build output, and local development files are excluded.
